# 客户端 v1 API（对外兼容接口）

> 代码位置：`apps/aether-gateway/src/api/ai/registry.rs`（路由注册）+ `api/ai/{openai,claude,gemini,jina,doubao,aliyun}.rs`（格式映射）
> Base URL：`https://<网关域名>`（生产）

## 一、鉴权（用户 API Key）

```bash
curl https://<网关域名>/v1/responses \
  -H "Authorization: Bearer sk-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx" \
  -H "Content-Type: application/json" -d '{...}'
```

- Key 格式：`sk-` 前缀 + 32 位随机字符（默认前缀 `sk`，可用环境变量配置）；库内只存哈希
- Key 由管理端 `POST /api/admin/api-keys` 创建（见 admin-api/02），受 `allowed_providers` / `allowed_models` / `allowed_api_formats` / `ip_rules` / `rate_limit` / `concurrent_limit` / 钱包余额约束
- 也支持 cookie（web 登录态）与 provider key 直连（信任头）等载体

### POST /v1/responses 请求体要求（铁律）

```json
{
  "model": "<模型名>",
  "input": [
    {
      "role": "user",
      "content": [
        { "type": "input_text", "text": "hi" }
      ]
    }
  ],
  "tools": [{"type": "function", "name": "shell_command", "parameters": {"type": "object", "properties": {}}}],
  "stream": true,
  "reasoning": {"effort": "high"}
}
```

> ⚠️ **`input` 必须是数组**（`[{"role":"user","content":[...]}]`）。若传字符串，网关 503「没有匹配到可用的执行路径」。
> `model` 必须是真实存在的全局模型名（如 `<模型名>`），否则无候选路由。

### POST /v1/chat/completions 请求体

标准 OpenAI chat 格式：

```json
{
  "model": "<模型名>",
  "messages": [{"role": "user", "content": "hi"}],
  "max_tokens": 4096,
  "stream": true
}
```

## 六、路由与格式转换

网关按入站格式自动做格式转换（`crates/aether-ai/formats`），转换规则集中在 `src/core/api_format/`（上游 Python 版同名目录）→ Rust 版在 `crates/aether-ai/formats`。

api_format → 入站路径映射（代码核实）：

```
openai:chat             → /v1/chat/completions
openai:responses        → /v1/responses
openai:responses:compact→ /v1/responses/compact
openai:embedding        → /v1/embeddings
openai:rerank           → /v1/rerank
openai:search           → /v1/alpha/search
openai:image            → /v1/images/generations
openai:video            → /v1/videos
claude:messages         → /v1/messages
gemini:generate_content → /v1beta/models/{model}:{action}
gemini:interactions     → /v1/interactions
gemini:files            → /v1beta/files
jina:embedding/rerank   → /v1/embeddings、/v1/rerank
doubao:embedding        → /v1/embeddings
```

## 七、错误格式

所有 v1 错误均为 OpenAI 风格：

```json
{
  "error": {
    "type": "invalid_request_error",
    "message": "详细错误",
    "param": null,
    "code": null
  }
}
```

常见错误场景（来自运维经验）：
- **400 Invalid schema**：请求里带了坏工具 schema（如 Codex `automation_update` type:null）→ 见 ops 已知问题 1
- **400 web_search_call**：Codex 会话历史带 `web_search_call` item 且 action 为字符串 → 见 ops 已知问题 6
- **400 null enum**：BrowserOS neo 工具 enum 含 null 打到 Gemini 渠道 → 见 ops 已知问题 8
- **502 流式首字节超时**：节点 tunnel 掐断 → 见 ops 已知问题 2
- **503 没有匹配到可用的执行路径**：input 不是数组 / 模型不存在 / 候选全部失败
